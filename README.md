# Котик в аду: бургеры

Моя небольшая браузерная игра про котика с бантиком, который попал в ад. Помогайте ему ловить бургеры и избегать шипов.

## Запуск

Откройте `index.html` в браузере. Никакие установки или сервер не нужны.

## Управление

- `←` и `→` или `A` / `D` — движение котика;
- на телефоне — касание игровой области или кнопки;
- обычный бургер: +1, двойной бургер: +3, шип: −2.
