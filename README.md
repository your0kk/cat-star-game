# Котик в аду: бургеры

Моя небольшая браузерная игра про котика с бантиком, который попал в ад. Помогайте ему ловить бургеры и избегать шипов.

## Запуск

Откройте `index.html` в браузере. Никакие установки или сервер не нужны.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в него **содержимое** папки `star-catcher` — так, чтобы `index.html` оказался в корне репозитория.
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем сохраните.

Через пару минут GitHub покажет адрес опубликованной игры.

## Управление

- `←` и `→` или `A` / `D` — движение котика;
- на телефоне — касание игровой области или кнопки;
- обычный бургер: +1, двойной бургер: +3, шип: −2.
